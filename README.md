# دعوة زفاف أحمد وأميرته

موقع ثابت مستقل. تحتاج Node.js 22.13+ (أو 24) وpnpm 11.25.0.

```bash
corepack enable
pnpm install
pnpm dev
```

لإنتاج النسخة النهائية ومعاينتها:

```bash
pnpm build
pnpm preview
```

ارفع محتويات `dist/` إلى أي استضافة Static. تفاصيل المنصات في [DEPLOY.md](DEPLOY.md). لا تحتاج قاعدة بيانات أو مفاتيح API أو سيرفر يعمل بعد البناء.

بيانات المناسبة في `lib/wedding-config.ts`. ملف الموسيقى الأصلي في `public/audio/wedding.mp3`؛ يبدأ فقط بعد ضغط الزائر «افتح الدعوة». الخطوط والصور والرخص محلية في `public/`. Google Maps وروابط التقويم والمشاركة خدمات خارجية يستدعيها المتصفح عند الحاجة.

`pnpm check` يتحقق من التواريخ والعد التنازلي وملف التقويم والأصول. الروابط المشاركة تستخدم رابط الصفحة المنشورة تلقائيًا، وليس نطاق الاستضافة السابق. وسوم معاينة المشاركة تستخدم صورة `og.png` بمسار نسبي؛ بعض خدمات المعاينة قد تتطلب رابطًا مطلقًا، ويمكن تعديل الوسم في `index.html` بعد اختيار النطاق النهائي من دون تغيير عمل الموقع.
